# mock_apps — макеты экранов приложений на Flutter

Восемь экранов обычных мобильных приложений на настоящих виджетах Material 3.
Интерфейс на русском, вёрстка в логическом холсте 360×640, кадр — 1080×1920.

## Экраны

У каждого приложения свой визуальный язык: шрифт, скругления, плотность,
способ подачи контента и тип навигации.

| Фрагмент URL | Приложение | Стиль |
|---|---|---|
| `#/flowers` | Флора — цветы | бутик: засечный Playfair, углы 2 px, витрина-лукбук без карточек, строка заказа снизу |
| `#/gas` | МойГаз — ЖКХ | утилитарный: PT Sans, плоские секции без теней, сегмент-контрол, таблица расхода, липкая кнопка |
| `#/taxi` | Поехали — такси | ночная карта: Manrope, тёмные панели, кислотный лайм, шторка с тарифами |
| `#/bank` | Капитал — банк | премиум: Montserrat, тёмно-синий с золотом, карусель карт, волосяные линии, плавающая пилюля |
| `#/weather` | Погода | иммерсивный: контент прямо на градиенте, сверхтонкие цифры, только линейки |
| `#/fitness` | Пульс — фитнес | неон: почти чёрный, крупные плитки 26 px, Rubik, островок навигации |
| `#/food` | Вкусно Домой — еда | яркий: Nunito, крупный заголовок вместо шапки, пастельные плитки, тёмная плашка корзины |
| `#/home` | Умный дом | системный: сгруппированные белые блоки, капслок-секции, плитки заливаются цветом, обычный таб-бар |

Общие вспомогательные виджеты (кольца, пончик, спарклайн, столбики) —
в `lib/theme.dart`; оформление каждого экрана живёт в его собственном файле.
Шрифты берутся через `google_fonts` — при первом запуске нужен интернет.

## Запуск

```
flutter run -d edge
```

Нужный экран открывается адресом с фрагментом, например
`http://localhost:PORT/#/gas`. Без фрагмента показывается экран цветов.

`main.dart` фиксирует логический холст 360×640 и растягивает его на всё окно
через `FittedBox`, поэтому картинка не зависит от размера окна браузера.

## Скриншоты

`shoot.ps1` собирает веб-сборку, поднимает локальный сервер и снимает все
восемь экранов в PNG 1080×1920.

```
powershell -File shoot.ps1 -Out ..\apps_flutter
```

## Важно про длинные пути

Windows не даёт Flutter создавать файлы, если путь к проекту длиннее ~260
символов — сборка падает на ассетах. Если проект лежит глубоко, скопируйте его
в короткий путь (например `C:\flm`) и собирайте оттуда, либо включите
поддержку длинных путей в Windows.
